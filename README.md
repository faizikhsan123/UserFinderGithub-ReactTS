# GitHub User Finder

Aplikasi untuk mencari profil dan repository GitHub.
Built with React + TypeScript.

## Demo
[link Vercel kamu]

## Fitur
- Cari user GitHub by username
- Tampilkan profile, bio, dan statistik
- List repository diurutkan by bintang
- Debounce search — tidak spam request
- Loading skeleton + error handling

## Tech stack
- React 18 + TypeScript
- Vite
- GitHub REST API
